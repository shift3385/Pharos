# App icons

Generated by the Tauri CLI from `../pharos-icon-source.png`. `tauri.conf.json`
references `32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`, `icon.ico`;
the `Square*Logo.png`/`StoreLogo.png` (Windows Store) and `android/` `ios/` sets
are also emitted for future targets.

## Source image

`pharos-icon-source.png` (1024×1024, transparent corners) is the redesign logo
(`src/shared/ui/Logo.tsx`, SPEC §11 in `docs/rediseno/SPEC.md`), full version with
`surface="navy"`, on a navy 900 (`#0b1f33`) square with 224 px rounded corners.
The 48-unit logo is scaled ×14.4 and offset 152 px, so the mark keeps a safe
margin of about 15 % on every side. Colors are the token values: accent
`#f2a33c` (ring, beams, lantern) and navy 300 `#6fa3cc` (tower).

It was rendered from an HTML page holding that inline SVG with headless Edge
(no extra dependency):

```
msedge --headless=new --disable-gpu --hide-scrollbars --default-background-color=00000000 --force-device-scale-factor=1 --window-size=1024,1024 --screenshot=pharos-icon-source.png file:///…/icon.html
```

To regenerate the icons after changing the source image, from `pharos/`:

```
npm run tauri icon src-tauri/pharos-icon-source.png
```

The browser favicon (`index.html`) is the compact logo (below 28 px) as an inline
SVG on the same navy square.
