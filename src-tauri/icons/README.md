# App icons

Generated by the Tauri CLI from `../pharos-icon-source.png` (a 1024×1024 navy +
amber beacon). `tauri.conf.json` references `32x32.png`, `128x128.png`,
`128x128@2x.png`, `icon.icns`, `icon.ico`; the `Square*Logo.png`/`StoreLogo.png`
(Windows Store) and `android/` `ios/` sets are also emitted for future targets.

To regenerate after changing the source image, from `pharos/`:

```
npm run tauri icon src-tauri/pharos-icon-source.png
```
