# Apéndice. Atajos de teclado

Todos los atajos del manual, capítulo a capítulo. Las letras de una pantalla (por ejemplo, P, F, B y S del ejecutor) solo actúan cuando no estás escribiendo en un campo.

### 1. Acceso y cuenta

| Tecla | Dónde | Qué hace |
| --- | --- | --- |
| Tab / Mayús+Tab | Formulario de entrada | Pasa de un campo al siguiente o al anterior |
| Intro | Formulario de entrada o de registro | Envía el formulario («Entrar» o «Registrarme») |
| Intro | «Mi perfil» | Guarda el alias y el nombre |
| ↑ ↓ e Intro | Selector de idioma y menú de usuario | Recorren las opciones y eligen una |
| Esc | Selector de idioma y menú de usuario | Cierra el menú y devuelve el foco a su botón |

### 2. La aplicación de un vistazo

Estos atajos funcionan en cualquier pantalla. Cada capítulo explica los suyos.

| Tecla | Qué hace |
| --- | --- |
| Ctrl+K (⌘K en Mac) | Abre la búsqueda. No actúa si hay un diálogo abierto |
| Tab / Mayús+Tab | Pasa al control siguiente o al anterior. El primer Tab de cada pantalla muestra «Saltar al contenido», que lleva directamente al contenido sin recorrer el menú |
| Intro o Espacio | Pulsa el botón o el enlace enfocado |
| Esc | Cierra el menú, panel o diálogo abierto y devuelve el foco al botón que lo abrió. En una confirmación normal equivale a «Cancelar»; las confirmaciones críticas (las que borran algo guardado para siempre) solo responden a sus botones |
| ↑ ↓ | Recorren las opciones de un menú (también el selector de proyecto) |
| Inicio / Fin | Saltan a la primera o a la última opción de un menú |
| ← → | Cambian de pestaña en las pestañas y en los controles segmentados (por ejemplo, Lista / Tablero) |

Dentro de un diálogo, Tab no sale de él: recorre solo sus controles hasta que
lo cierras.

### 3. Inicio

| Tecla | Dónde | Qué hace |
| --- | --- | --- |
| Tab | Inicio | Recorre las tarjetas (son enlaces) y los paneles en orden |
| Intro | Una tarjeta o una fila de «Próximas pruebas» | La abre |

### 4. Proyectos

| Intro | El nombre de un proyecto | Lo abre |

### 5. Plan de pruebas

| Tecla | Dónde | Qué hace |
| --- | --- | --- |
| Tab / Mayús+Tab | Cualquier paso | Recorre los campos; al cambiar de paso, el foco va a su título |
| Intro | «Especifica otro…» (tipos), «Otro entregable», «¿No está en la lista?» (herramientas) | Añade lo escrito |
| Intro | Fecha de un sprint o un hito (dd/mm/aaaa) | Aplica la fecha; salir del campo también la aplica |
| ← → | Calendario del cronograma | Día anterior o siguiente |
| ↑ ↓ | Calendario del cronograma | Semana anterior o siguiente |
| Inicio / Fin | Calendario del cronograma | Primer o último día de la semana |
| RePág / AvPág | Calendario del cronograma | Mes anterior o siguiente |
| Intro o Espacio | Calendario del cronograma | Marca el día enfocado (inicio o fin del sprint, o un hito) |
| Esc | Calendario del cronograma | Cancela el sprint que estás marcando |

### 6. Tablero

| Tecla | Dónde | Qué hace |
| --- | --- | --- |
| Tab | Tablero | Recorre los filtros, el buscador y, en cada tarjeta, su asa, su título y su papelera |
| Espacio o Intro | Asa de una tarjeta (⠿) | Coge la tarjeta para moverla; otra vez, la suelta |
| ← → | Tarjeta cogida | La lleva a la columna anterior o a la siguiente |
| ↑ ↓ | Tarjeta cogida | La sube o la baja dentro de su columna |

| Intro | Título de una tarjeta | La abre en el editor |
| ↑ ↓ e Intro | Menú «Prioridad» | Marcan o desmarcan cada prioridad |

### 10. Ejecuciones e importación de resultados

| --- | --- | --- |

### 11. Ejecución manual

| Tecla | Qué hace | Dentro de un campo |
| --- | --- | --- |
| P | Marca el paso enfocado como Pasa y salta al siguiente sin marcar | No |
| F | Lo marca como Falla, se queda en él y abre «Obtenido / notas» | No |
| B | Lo marca como Bloqueado, se queda en él y abre las notas | No |
| S | Lo marca como Omitido y pasa al siguiente | No |
| J o ↓ / K o ↑ | Paso siguiente / anterior | No |
| N | Abre «Obtenido / notas» del paso | No |
| T | Pone en marcha o pausa el cronómetro | No |
| ? | Muestra la lista de atajos | No |
| Ctrl+Enter (⌘+Enter) | Guarda el resultado | Sí |
| Ctrl+Mayús+N | Pasa al siguiente elemento del run | Sí |
| Ctrl+V | Pega la captura del portapapeles en el paso enfocado o en el resultado | Sí |

Las letras no hacen nada mientras escribes en un campo, con Ctrl o Alt
pulsado, con un diálogo abierto o en un run cerrado. En un run cerrado solo
funcionan «?» y Ctrl+Mayús+N.

### 12. Defectos

| Tecla | Dónde | Qué hace |
| --- | --- | --- |
| ← → | Filtro de estado (Abiertos · Todos · Cerrados) y «Lista / Tablero» | Cambian de opción |
| Espacio o Intro | Asa de una tarjeta del tablero | La coge para moverla; otra vez, la suelta |
| ← → | Tarjeta cogida | La lleva a la columna anterior o siguiente |
| Esc | Tarjeta cogida | Cancela el movimiento; la tarjeta vuelve a su sitio |
| Esc | Quitar el vínculo con un resultado | Equivale a «Cancelar» |
| Esc | Quitar una evidencia o eliminar un defecto | No la cierra: usa «Cancelar» |

### 14. Ajustes del proyecto
