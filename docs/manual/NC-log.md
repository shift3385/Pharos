# Registro de no conformidades del manual v2 (MAN-03)

Este registro anota, en orden, las no conformidades (NC) encontradas al recorrer
la app flujo a flujo para redactar el manual. Si una NC es pequeña y no hace
falta decidir nada, se corrige antes de tomar la captura y se apunta como
**resuelta en el momento**. Si necesita una decisión o es grande, queda
**pendiente** y se resuelve después con el responsable de QA, una a una.

Gravedad:

- **Alta:** rompe la app o hace perder datos.
- **Media:** confunde o bloquea un flujo.
- **Baja:** texto o detalle.

Las rutas de archivo son relativas al repositorio.
