# ADR-0045 · Contraseña de la cuenta: cambiarla, códigos de recuperación y restablecerla (SEC-08, SEC-09)

- **Estado:** Propuesto.
  - Las decisiones de dirección las aprobó el usuario el 2026-11-17 («Sí, apruebo todo»).
  - Pasa a «Aceptado» cuando el usuario apruebe el plan y los bocetos de la pista C.
- **Contexto:**
  - Hoy no hay forma de cambiar ni de recuperar la contraseña de la cuenta del servidor.
  - No hay que confundirla con la clave de recuperación de la base de datos local (SEC-03, ADR-0024), que protege los datos del equipo y no la cuenta.
  - El servidor autoalojado no envía correo: el ADR-0019 dejó el SMTP «para el despliegue (0.5.0)».
- **Decisión (aprobada como dirección):**
  - **SEC-08:**
    - «Mi perfil › Cambiar contraseña» pide la actual;
    - al registrarse se generan **códigos de recuperación de un solo uso**, que se muestran una vez y se guardan con hash en el servidor (migración `0021`);
    - con un código se fija una contraseña nueva y **se cierran las demás sesiones** (refresh tokens revocados);
    - los datos locales no se tocan.
  - **SEC-09 por correo:**
    - el **SMTP es opcional y está apagado por defecto** (variables `SMTP_*`);
    - sin ellas, «¿Olvidaste la contraseña?» ofrece los códigos de recuperación y la ayuda de un administrador;
    - el enlace es de un solo uso, caduca y se guarda con hash (migración `0022`);
    - la respuesta no dice si un correo existe.
  - **SEC-09 por administrador (ola 2, después de SYNC-07):**
    - un Test Manager del workspace genera un enlace o código de restablecimiento para un miembro, sin ver ni fijar la contraseña;
    - el restablecimiento queda en la auditoría.
  - En los límites de intentos se reutiliza lo que ya tiene el login.
- **Alternativas:**
  - Correo obligatorio: añade una dependencia que una instalación aislada no puede cumplir.
  - Que el administrador fije la contraseña: la conocería y no quedaría claro quién la puso.
- **Consecuencias:**
  - La pista C toca `server/src/modules/auth/**`, `src/modules/auth/**` y `src/modules/profile/**`.
  - La guía de despliegue (ADR-0046) explica las variables `SMTP_*`.
