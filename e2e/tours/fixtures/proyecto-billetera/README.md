# Billetera SafeGuard

Aplicación móvil de billetera digital. Ejemplo para el manual de Pharos
(«Requisitos desde un proyecto»): documentación y código pequeños, sin datos
reales.

## Funciones

- Acceso con correo o usuario y contraseña, «Recordarme» y recuperación de la
  contraseña. También con Google, FaceID o huella.
- Inicio con el saludo, el saldo de la cuenta principal y las acciones rápidas:
  pagar o enviar, recargar, ver el estado de cuenta y retirar en cajero.
- Varias billeteras (por ejemplo, en USD) y los últimos movimientos.
