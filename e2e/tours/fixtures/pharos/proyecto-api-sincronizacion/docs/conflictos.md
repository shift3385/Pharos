# Conflictos

- Si dos personas cambian **campos distintos** del mismo elemento sin
  sincronizar, Pharos combina los dos cambios sin preguntar y avisa: «Se
  combinaron cambios de otra persona en 1 elemento».
- Si cambian **el mismo campo** con valores distintos, el panel de conflictos
  pregunta solo por ese campo: quedarse con el valor de este equipo o con el
  del servidor.
- Un texto largo (la descripción, por ejemplo) no se mezcla: se elige uno.
- Borrar en un equipo y editar en otro es siempre un conflicto del elemento
  entero.
- Cada fusión queda en la auditoría como «Conflicto resuelto · Combinado».
